# Prvctice — Voice Command Reference

A quick guide to every built-in phrase you can speak instead of tapping around. You can speak naturally. If the phrase matches, the UI responds instantly; otherwise your words are treated as a normal chat message.

## Navigation

---

| Action      | Say…                                  |
| ----------- | ------------------------------------- |
| Open Notes  | “open notes”, “show notes”            |
| Close Notes | “close notes”, “hide notes”           |
| Open Help   | “open help”, “show help”, “show tips” |
| Close Help  | “close help”, “hide help”             |
| Toggle Help | “help”, “tips”                        |
| New chat    | “start a new chat”                    |

## Notes

---

| Action                            | Say…                        |
| --------------------------------- | --------------------------- |
| Ask assistant about selected text | “what do you think?”        |
| Email your notes                  | “email notes”, “mail notes” |

## Attachments & Media

---

| Action                  | Say…                           |
| ----------------------- | ------------------------------ |
| Add an image attachment | “attach an image”, “add image” |
| Show / hide pet         | “where’s Lulu?”                |

## Workspace & Layout

---

| Action                   | Say…                                     |
